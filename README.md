# Your Pixel Portfolio

A responsive, pixel-inspired personal portfolio made with plain HTML, CSS, and JavaScript. It has no framework or build step.

## Run it

Open `index.html` in a browser, or serve this folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before you submit: personalize it

The page now includes your supplied display name and email. The three project cards are still clearly marked starter/demo examples; replace them with work you actually made before submitting.

1. Review the short bio in `index.html` and edit it so it sounds like you.
2. Replace each project title, explanation, technology tags, and project artwork with your real work and its real link. The current cards are example ideas, not claims about work you have done.
3. Add your real school/grade (if you want to share it), interests, and next learning goal to the About and Toolbox sections. Avoid posting private details such as your home address, personal phone number, or exact daily routine.
4. Your supplied email is linked in the contact button. Confirm you're comfortable sharing it publicly before publishing the portfolio.
5. Adjust the palette near the top of `style.css` if you want your own colors.

The illustration, textures, layout, and project mini-art are CSS/HTML. There are no images, font downloads, frameworks, or external JavaScript libraries.
