# Design notes

- **Artifact / audience:** Personal portfolio for a teen creator, intended for a techathon submission; laptop and phone.
- **Visual language:** Warm, indie pixel-art world; editorial portfolio layout with playful arcade-inspired labels and clear project hierarchy.
- **Mode:** Greenfield.
- **Five dials:** Visual variance 7 (custom pixel scene, varied card illustrations, stable nav and grid); motion 3 (hover feedback, status blink, restrained moving ticker; all reduced when requested); information density 4 (concise, scannable project cards); asset dependence 2 (no personal assets were supplied; CSS artwork is decorative and projects are explicitly starter content); brand fidelity 2 (new identity, user can retheme).
- **Four positioning answers:** The hero leads; laptop-and-phone readability; energetic / handmade warmth; sections stay short and scannable.
- **Palette:** Warm paper `#f7f3e9`, dark ink `#24221e`, violet `#7357df`, mint `#c9e8c9`, coral `#ff795e`, sun `#f8d65b`.
- **Typography:** Trebuchet/Avenir-style display and body stacks, monospace labels; no external fonts required.
- **Spacing / shape:** 4px/8px rhythm, intentionally crisp edges, pixel-offset shadows.
- **Motion:** Short transitions and small decorative movement, with `prefers-reduced-motion` support.
- **Content status:** Ranabir Kumar Roy's supplied name and email are now used in the page. Project cards remain clearly labeled starter examples; no project accomplishments or personal statistics are claimed as facts.
